# Módulo 3 — E-Commerce: Carrito de Compras y Autenticación

## 📌 Descripción del proyecto
Este proyecto corresponde a una actividad de portafolio del Módulo 3, cuyo objetivo es desarrollar un sitio web de tipo e-commerce utilizando **HTML, CSS, JavaScript y Bootstrap 5**.

La aplicación implementa un **catálogo de productos**, un **carrito de compras funcional** y un **flujo básico de autenticación**, aplicando estructuras de datos, funciones y sentencias condicionales en JavaScript.

---

## 🎯 Objetivos de la actividad
- Aplicar arreglos y objetos para la gestión de productos.
- Implementar lógica de carrito de compras (agregar y quitar productos).
- Calcular el total de compra y aplicar un código de descuento.
- Utilizar Bootstrap 5 para un diseño responsivo.
- Implementar autenticación básica mediante un modal.
- Organizar el proyecto en una estructura clara de archivos.

---

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

## 🛒 Funcionalidades principales

### Catálogo de productos
- Catálogo definido como un arreglo de objetos.
- Cada producto incluye: id, nombre, precio y estado de descuento.
- Visualización de productos mediante tarjetas (cards) de Bootstrap.

### Carrito de compras
- Agregar productos al carrito.
- Quitar productos individualmente.
- Visualización del carrito en una tabla.
- Cálculo automático del total.

### Código de descuento
- Código válido: **DESC15**
- Aplica un 15% de descuento al total de la compra.

### Autenticación básica
- Inicio de sesión mediante Modal de Bootstrap.
- Validación de contraseña usando una contraseña maestra.
- Mensajes de confirmación o error para el usuario.

---

## 📱 Diseño responsivo
El diseño se implementó utilizando el sistema **Grid de Bootstrap**, asegurando una correcta visualización en dispositivos móviles, tablets y escritorio.  
El estilo visual se inspira en una estética minimalista tipo **ZARA**, utilizando una paleta monocromática.
